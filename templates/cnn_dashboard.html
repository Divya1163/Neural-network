What is a CNN?

A Convolutional Neural Network is a deep learning model specialized for image-like data. It automatically learns useful visual features such as edges, textures, and shapes.

Why is CNN used?

CNNs reduce parameters with shared filters, preserve spatial information, and achieve strong performance in image classification, object detection, segmentation, and medical imaging.

Why This Matters

Plain English: A convolution filter scans small neighborhoods and highlights useful patterns like edges or texture.

Math: y(i,j) = sum(sum(x(i+m, j+n) * k(m,n))).

Real-world analogy: Think of a stencil moving over a photo. At each position it scores how strongly a pattern appears.

Parameter Impact Preview

  • Resize: 224 x 224 keeps rich details for feature learning.
  • Kernel: Edge detection highlights boundaries and shape contours.
  • Stride: 1 scans every location for full detail.
  • Padding: 1 preserves border information.
  • Filters: 1 filter means one type of pattern detector.
  • Preprocessing: Normalize stabilizes responses across brightness changes.

Advanced Controls (Optional)

What is Stride?

Stride is how far the kernel jumps each move. Bigger stride = faster scan, less detail.

What is Padding?

Padding adds border pixels so edges are not ignored and output size can stay larger.

What is Number of Filters?

Each filter learns a different visual detector, so more filters capture more patterns.
