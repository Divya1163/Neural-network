What is an RNN?

A Recurrent Neural Network is a deep learning architecture designed for sequential and time-series data. It maintains a hidden state that captures temporal context, allowing it to understand patterns across timesteps.

Real-World Analogy

Like reading a sentence word by word, an RNN doesn't just look at the current word—it remembers previous words to understand context. The hidden state acts like your short-term memory, constantly updated as you read.

RNN Architecture Explained

Understanding how RNNs maintain and process sequential information.

RNN Network Topology

Key Components

Input Layer (xt)

Receives data at each timestep. Example: a single number from a sequence.

Like reading the current word in a sentence.

Hidden State (ht)

The network's memory. It processes input combined with previous hidden state to capture temporal patterns.

Like your current understanding so far.

Output Layer (yt)

Produces predictions based on the current hidden state. Can be a value, probability, or classification.

Represents your prediction of what comes next.

Recurrent Connection (Whh)

Feeds the hidden state back into itself. This is what makes RNNs "recurrent" and able to process sequences.

Acts as a memory feedback loop.

The Forward Pass Equations

Hidden State Update:

ht = tanh(Whh·ht-1 + Wxh·xt + bh)

Combines previous memory (ht-1) with new input (xt) through learned weights

Output Prediction:

yt = Why·ht + by

Makes prediction from current hidden state

Backpropagation Through Time (BPTT)

How gradients flow backward through the sequence to train the network.

The BPTT Process

While normal backprop works backward through layers, BPTT works backward through time. Gradients must flow back through all timesteps in the sequence.

  1. Forward Pass: Process entire sequence, storing hidden states at each timestep
  2. Compute Loss: Compare predictions to targets across all timesteps
  3. Backward Pass (BPTT): Gradients flow backward from output → hidden → input, accumulating across time
  4. Update Weights: Adjust Whh, Wxh, Why based on accumulated gradients

The Challenge: Vanishing/Exploding Gradients

The Problem

As gradients flow backward through many timesteps, they can become extremely small (vanishing) or extremely large (exploding), making training impossible.

  • Vanishing: Gradients → 0, network learns short-term patterns only
  • Exploding: Gradients → ∞, training becomes unstable (NaN)

Common Solutions

  • Gradient Clipping: Cap gradient magnitude to prevent explosion
  • LSTM/GRU: Gates control information flow, prevent vanishing gradients
  • Layer Normalization: Stabilize gradient magnitudes
  • Residual Connections: Create highways for gradients to skip timesteps

Mathematical Reference

Gradient w.r.t. Whh:

∂L/∂Whh = Σt (∂L/∂ht) · (∂ht/∂Whh)

Sum of gradients from all timesteps (this is the chain rule through time!)
