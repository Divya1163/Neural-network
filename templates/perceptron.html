Build intuition and validate behavior with AND, OR, and custom perceptron training in one analysis-first workspace.

Neural Fundamentals

Train and audit perceptrons like an engineer

Start with simple gates, inspect each update, then generalize to your own linearly separable dataset. Every step is visible: weighted sum, activation, error, and parameter updates.

Forward: z = (w1 * x1) + (w2 * x2) + b Activation: y_hat = 1 if z >= 0 else 0 Update: wj = wj + alpha * (y - y_hat) * xj

Quick Workflow

  1. Load dataset and set hyperparameters.
  2. Train and inspect epoch 1 walkthrough table.
  3. Analyze convergence and final decision state.
  4. Run predictions to verify model behavior.
