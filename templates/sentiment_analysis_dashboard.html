Key Concepts Explained

SimpleRNN Layer

Processes token sequences step-by-step and captures local contextual order in text.

Embedding Layer

Maps tokens to low-dimensional vectors so the network learns semantic proximity.

Label Encoding

Notebook maps sentiment classes to index values and transforms labels to one-hot vectors.

Softmax Activation

Converts output logits into class probabilities for positive, negative, and neutral labels.

Sequence Padding

All sequences are padded to the same length so batch operations are consistent.

Inference Pipeline

Input text follows the same tokenizer and padding path as training for reliable predictions.
